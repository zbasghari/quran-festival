# 🕌 سایت جشنواره قرآنی

یک پلتفرم جامع و مدرن برای خواندن، گوش دادن و تعامل با قرآن کریم

## ✨ ویژگی‌ها

- 📖 خواندن قرآن کریم با ترجمه
- 🎧 پخش صدای تلاوت با قاریان مختلف
- 💬 حدیث روز
- 🕐 اوقات شرعی شهرهای مختلف
- 🔍 جستجو در سوره‌ها
- 🔖 نشانک‌گذاری آیات
- 📿 تسبیح دیجیتال
- 🌙 حالت شب/روز
- 📱 طراحی ریسپانسیو

## 🚀 نصب و راه‌اندازی

### روش ۱: استفاده مستقیم

1. فایل‌ها را دانلود کنید
2. فایل `index.html` را در مرورگر باز کنید

### روش ۲: آپلود در GitHub Pages

1. یک مخزن جدید در GitHub ایجاد کنید
2. فایل‌ها را آپلود کنید
3. از بخش Settings > Pages گزینه GitHub Pages را فعال کنید
4. سایت شما در آدرس `https://username.github.io/repository-name` در دسترس خواهد بود
